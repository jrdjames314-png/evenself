# Evenself: AI twin demo

Evenself is a concept demo of an "AI twin": one person's finances, health, relationships, career and habits in one place, with a twin that analyzes them and answers questions.

> **Everything here is fictional.** The persona (Jordan Ellis, 31, Portland), the companies and every number are generated by `tools/generate_persona.py`. Nothing on the site is medical or financial advice.

This is a static site with no backend, no API keys, no build step and no tracking. All analysis runs in the visitor's browser.

## Features
- **Life Score (0–100)** combines Finance, Health, Relationships and Career & Goals scores. The formulas are in `js/analytics.js`.
- **Tabs with charts (Chart.js 4, bundled in `vendor/`):**
  - **Finance:** monthly spending by category, a breakdown of last month, budget vs actual, credit score trend, net worth, and accounts and debts.
  - **Health:** sleep vs goal, mood vs sleep, steps, blood pressure (with a 120/80 reference line), weight with a 7-day average, and workout mix.
  - **Relationships:** days since last contact vs your target for each person, check-ins per week, people cards, and important dates.
  - **Career & Goals:** goal progress, a skills radar, salary vs a market range, deep work vs meetings, and a habits table. The Overview tab adds a 30-day habit heatmap.
- **Computed insights:** each tab shows 3–5 insights generated by `js/insights.js` from the data, such as "Sleep under 7h on 10 of the last 14 nights" or "Haven't contacted Mom in 12 days". The data decides the thresholds, tone and wording, so editing the JSON changes the insights.
- **"Talk to your AI twin" chat:** an honest intent matcher (`js/twin-brain.js`) that answers from the computed numbers. It covers spending by category and month, "can I afford $X", budget, savings, debt, credit, sleep, blood pressure, weight, exercise, mood, who to call, specific people, birthdays, career and raises, goals, habits, and the overall score. Suggested-question chips are included. Finance and health answers carry a disclaimer.
- **Display:** dark and light themes (follows the system setting, with a toggle that's remembered) and a responsive layout. On phones the chat becomes a bottom sheet opened with the "Ask your twin" button.
- **Opening without a server:** `data/persona.js` mirrors `data/persona.json`, so `index.html` also works when opened straight from disk.

## Structure
```
index.html              page shell
css/styles.css          design system, light/dark, responsive
js/analytics.js         data → twin model (metrics + scores)
js/insights.js          twin model → insights
js/twin-brain.js        chat: askTwin() swap point + built-in intent logic
js/app.js               rendering, charts, tabs, chat UI
data/persona.json       fictional persona (canonical data)
data/persona.js         same data as a script (generated)
vendor/chart.umd.min.js Chart.js 4.4.4 (MIT)
tools/generate_persona.py  regenerates the persona (seeded, deterministic)
tools/check_model.js       node sanity check: scores, insights, chat answers
tools/screenshots.py       local server + headless Chrome test + screenshots
screenshots/            captured screenshots
```

## Run locally
```bash
cd ai-twin-demo
python3 -m http.server 8000      # then open http://localhost:8000
```
Other commands:
- Regenerate the data: `python3 tools/generate_persona.py`
- Quick logic check: `node tools/check_model.js "can I afford a \$1,200 trip"`
- Browser test and screenshots: `python tools/screenshots.py` (needs `pip install playwright` and Chrome or Chromium)

## Connecting a real AI model later
All chat goes through one function, `askTwin(question, model, history)`, in `js/twin-brain.js`. To connect a model:
1. Set `TWIN_CONFIG.mode = 'llm'` and `TWIN_CONFIG.endpoint` to your own serverless function, such as a Netlify Function, Vercel or Cloudflare Worker.
2. That function receives `{question, history, context}` and returns `{text}`. `context` comes from `buildTwinContext()`, a compact numbers-only summary of the persona.
3. Keep the API key on the server. Never put a key in this static site.

## Deploy (free)
Nothing has been deployed yet.

**GitHub Pages**
1. Create a GitHub repo and push the contents of this folder (`index.html` at the repo root). `.nojekyll` is already included.
2. Go to Settings → Pages → Build and deployment, choose "Deploy from a branch", then pick `main` and `/ (root)`.
3. The site goes live at `https://<user>.github.io/<repo>/` within about a minute.

**Netlify**
- Fastest: log in at app.netlify.com and drag this folder onto "Deploy manually".
- Or connect the GitHub repo. `netlify.toml` already says "no build, publish the root".
- Optional: add a custom domain (about $10–15/yr) in Site settings → Domain management.

## Before turning this into a real product
- Real personal data needs accounts and authentication, encryption at rest and in transit, a clear privacy policy, per-source consent, and data export and delete. Health data may fall under HIPAA or state health-privacy laws, depending on how it's offered.
- Keep the "not medical or financial advice" wording, and have someone qualified review any advice-like features.
- **Name check (Oct 2026):** a quick web search found no software or AI product called "Evenself" (only an Australian chemicals company that used the name in the 1990s). "TwinOS" (pending US trademark for AI software), "MirrorMe" (several AI apps) and "TwinWard" (registered TW trademark) were ruled out. This was not a legal trademark clearance, so do a USPTO search before investing in the brand.
